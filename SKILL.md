# Basic Calculator

## Instructions

Call the `run_js` tool using `index.html` and a JSON string for `data` with the following fields:
- **expression**: Required. A string representing the mathematical expression to evaluate (e.g., "2 + 2", "10 * (5 - 3)").

**Constraints:**
- Provide only the evaluated result. If the expression is invalid, return an error message.
